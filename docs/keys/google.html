Google Cloud Text-to-Speech-Schlüssel

Damit spricht Parley. Der Schlüssel ist kostenlos — Google gibt jeden Monat 1 Million Zeichen gratis, mehr als genug für den Alltag.

≈ 3 Minuten · Kreditkarte nötig, wird aber nicht belastet

  1. Google Cloud Console öffnen

    Öffne die Google Cloud Console und melde dich mit deinem Google-Konto an.

  2. Projekt anlegen

    Oben in der Leiste auf die Projektauswahl klicken → Neues Projekt → einen Namen vergeben (z. B. „Parley“) → Erstellen. Danach das Projekt oben auswählen.

  3. Text-to-Speech-API aktivieren

    Oben nach Cloud Text-to-Speech API suchen, öffnen und auf Aktivieren klicken. Falls nach Abrechnung gefragt wird: Zahlungsprofil hinterlegen — das Gratis-Kontingent bleibt kostenlos.

  4. Zu „Anmeldedaten“ wechseln

    Links im Menü (≡) → APIs & Dienste → Anmeldedaten (englisch: Credentials).

  5. API-Schlüssel erstellen

    Oben auf + Anmeldedaten erstellen → API-Schlüssel. Der Schlüssel wird sofort erzeugt.

  6. Schlüssel kopieren & einfügen

    Den Schlüssel kopieren und in Parley in das Feld Google Cloud TTS einfügen. Optional: den Schlüssel auf die Text-to-Speech-API beschränken.

Fertig — zurück in Parley auf Schlüssel prüfen klicken. Wird er grün, geht’s weiter.
