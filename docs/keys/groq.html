Groq-Schlüssel

Damit versteht Parley deine Sprache (Transkription & Einordnung deiner Antwort). Groq ist für Entwickler kostenlos — kein Zahlungsmittel nötig.

≈ 1 Minute · kostenlos, keine Kreditkarte

  1. Groq Console öffnen

    Öffne die Groq Console und melde dich an (mit Google oder GitHub).

  2. Zu „API Keys“ gehen

    Links im Menü auf API Keys klicken.

  3. Schlüssel erstellen

    Create API Key klicken, einen Namen vergeben (z. B. „Parley“) und bestätigen.

  4. Schlüssel kopieren & einfügen

    Der Schlüssel wird nur einmal angezeigt — sofort kopieren und in Parley in das Feld Groq einfügen.

Fertig — zurück in Parley auf Schlüssel prüfen klicken. Wird er grün, geht’s weiter.
